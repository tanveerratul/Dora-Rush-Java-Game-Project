# Dora-Rush-Java-Game-Project
This repository contains the source code and the installable file of my project Dora Rush. A project created for my object oriented programming course in 2022.

Dora Rush is basically a pacman game but Doraemon themed. Doraemon is the main character of the game. we can control the character with our keyboard.

Controls:
< = Left
> = Right
^ = Up
v = Down

esc = pause
space = play

Game Objective:
The map of the game is divided into 400 blocks. some blocks are blocked with walls and rest are filled with dora cakes. Besides there will be some mouse roaming along the map. The main purpose of the game is to drive the main character throughout the whole map to collect all the dora cakes avoiding the mice. Each cake contains one point. The player have to collect all the dora cakes avoiding the mice to get to the next level. In each level the number and the speed of the mouse increases to make it more difficult t complete. Once the player colides with a mouse it looses a chance and gets back to the starting location. If the player colides with mice three times, the game restarts.
